🚀 How to Use

⚙️ CLI Usage (Recommended)
For actual report generation, use the Python CLI:

python ddr_generator.py --inspection report1.pdf --thermal report2.pdf --output ./output

Setup Instructions:

  1. Install dependencies: pip install -r requirements.txt
  2. Set API key: export ANTHROPIC_API_KEY='your-key'
  3. Run the generator with your PDFs
  4. Find output in the specified output directory

📋 DDR Report Structure

The generated report includes:

  1. Property Issue Summary - Overview of property and main issues
  2. Area-wise Observations - Detailed findings by location
  3. Probable Root Cause - Analysis of underlying issues
  4. Severity Assessment - Risk evaluation with reasoning
  5. Recommended Actions - Immediate, short-term, and long-term steps
  6. Additional Notes - Conflicts, clarifications, observations
  7. Missing Information - Explicitly noted data gaps
